# AI Resume Analyzer 🤖

A Generative AI based application that analyzes a resume against a job description.

## Features

- Resume PDF upload
- Job description analysis
- Resume-job match score
- Matching skills identification
- Missing skills detection
- Strength analysis
- Improvement suggestions
- AI-generated interview questions

## Tech Stack

- Python
- Streamlit
- Google Gemini API
- PyPDF

## How It Works

Resume PDF + Job Description
→ PDF Text Extraction
→ Gemini Generative AI
→ Resume Analysis
→ Match Score & Recommendations
